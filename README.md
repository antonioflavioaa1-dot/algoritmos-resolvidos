# Algoritmos resolvidos em Kotlin (11 a 120)

Este projeto contém **110 arquivos Kotlin**, um para cada algoritmo numerado de 11 a 120 no material de referência.

## Organização

Os arquivos estão separados em pastas de dez exercícios:

- `11-20`
- `21-30`
- `31-40`
- `41-50`
- `51-60`
- `61-70`
- `71-80`
- `81-90`
- `91-100`
- `101-110`
- `111-120`

Cada arquivo tem um comentário com um enunciado curto e uma solução independente em Kotlin, com sua própria função `main()`.

## Como executar

Abra o arquivo `.kt` que deseja testar em uma IDE Kotlin, como IntelliJ IDEA ou Android Studio, e execute a função `main()` daquele arquivo. Cada exercício é independente; execute um arquivo por vez.

Os programas leem os dados pelo console. Quando necessário, podem ser digitados números com vírgula ou ponto decimal.

## Observações sobre a adaptação

- O material de referência usa pseudocódigo/UAL; os programas foram reescritos em Kotlin.
- Algumas entradas foram protegidas contra situações como divisão por zero, logaritmo inválido ou raiz quadrada de número negativo.
- O livro repete o número **24** em duas versões consecutivas. Para manter exatamente 110 arquivos com numeração contínua de 11 a 120, o arquivo `Algoritmo24.kt` contém a versão com a operação de divisão entre parênteses, apresentada como correção no próprio material.
- Os enunciados nos comentários são resumos curtos, não transcrições integrais do texto do livro.
